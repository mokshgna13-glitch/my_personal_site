# MOKSHGNA. Personal Portfolio

My personal portfolio website where I showcase my projects and experiments and my interests and my journey as I learn and build things.

I wanted the site to feel more like my own digital workspace than a normal portfolio so I went for a slightly messy developer aesthetic with floating particles rough borders terminal-style text and interactive elements.

## 🎨 Design

I wanted to avoid making the site look like a polished template.

The visual style uses:

* yellow background

* Dark green borders and text

* Pink green and blue buttons

* Handwritten typography

* Terminal-inspired project descriptions

* Borders and shadows

* Space-like floating particles

The goal is for the website to feel built experimented with and constantly evolving.
